### OD-07 로그인 유지(Remember)
- 스토리보드: "사용자의 이메일과 비밀번호를 자동 저장해 주는 체크박스", 체크하면 자동 로그인.
- 상세 설계: 체크하면 Refresh 토큰 14일 유지, 안 하면 브라우저를 닫을 때 세션 종료, 기본 미체크(DTL-AUT-035). Refresh 토큰은 HttpOnly 쿠키, Access 토큰은 메모리에만, localStorage 금지(DTL-AUT-036).
- 추천: 상세 설계(토큰 방식). 비밀번호를 기기에 저장하면 기기가 털렸을 때 비밀번호까지 새고, 비밀번호를 바꿔도 그 기기의 자동 로그인을 막을 수 없다.
- 더 정할 것
  - 14일을 로그인 때부터 셀지, 재발급할 때마다 다시 셀지. 가짜 서버는 로그인 때부터 센다 [임시 가정].
  - 다시 접속했을 때 '로그인한 적 없음'과 '만료'를 구분할지. 웹에서는 14일이 지나면 브라우저가 쿠키를 지워 서버도 구분하지 못한다. 그래서 지금은 서버가 만료·폐기를 알릴 때만 "로그인이 만료되었습니다" 문구(DTL-AUT-039)를 띄운다.
  - 복원 중 네트워크 오류: 지금은 로그아웃시키지 않고 '다시 시도'로 둔다 [임시 가정].
  - 앱이면 '미체크'는 앱을 완전히 닫을 때 끝나는지.
- 지금 코드: `src/auth/session.ts`, 가짜 서버 `src/adapters/fake/fakeSessionServer.ts`.

## 홈

### OD-22 홈 화면 구성 — 스토리보드와 요구사항이 다름
- 하단 탭: 스토리보드는 홈·캘린더·AI·메모·설정 5개(순서는 글자 인식으로 확인하지 못함). 요구사항·상세 설계는 홈·캘린더·프로젝트·검색/비서·설정(REQ-HOM-002, DTL-HOM-002). 스토리보드에는 '프로젝트' 대신 '메모'가 있다. 'AI'가 '검색/비서'인지 확인.
- 홈 내용: 스토리보드에는 주간 브리핑 카드("이번주 일정 0건 및 할 일 0건"), 오늘 일정·마감 임박·검증 필요 개수, 최근에 물어본 내용, 최근 프로젝트·최근 열람이 있다. 요구사항(REQ-HOM-001)의 '중요 메모'는 글자로는 보이지 않는다. 주간 브리핑 카드·최근 질문·최근 열람은 요구사항에 없다 — 범위에 넣을지.
- 빠른 입력 (+) 버튼(REQ-HOM-003, DTL-HOM-003)은 아이콘이라 글자 인식으로 확인하지 못했다.
- 용어: 스토리보드 '검증 필요' / 요구사항 '확인 필요'(REQ-UX-001).
- 결정: 2026-10-04 · 명세서 v5 · 모바일 하단 탭은 홈·캘린더·메모·할 일·검색/비서, 프로젝트·설정은 홈 상단 메뉴, 데스크톱은 7개 모두 좌측 사이드바(DTL-HOM-002, 팀 확정 대기). 용어는 '확인 대기'(REQ-UX-001·HOM-007). 홈의 주간 요약·최근 AI 질문·최근 프로젝트·최근 열람 메모는 요구사항으로 들어갔다(REQ-HOM-006·008~010). '검증 필요'를 누르면 어디로 가는지는 아직 열려 있다(DTL-HOM-005).

## 스토리보드 자체

### OD-24 스토리보드 정리
- 받은 11장은 로그인·회원가입·이메일 인증·비밀번호 재설정·홈만 다룬다. 초기 설정, 캘린더, 할 일, 프로젝트, AI 확인, 비서, 브리핑, 휴지통, 앱 잠금 화면이 따로 있는지.

- '이메일 인증 실패' 화면 2번(코드 만료) 설명이 '비밀번호 불일치' 설명과 같다. 복사 실수로 보인다.
- 'Eamil', 'Set pssword', 가입 버튼 이름 'Membership'이 실제 표기인지(글자 인식 오류일 수도 있다).
