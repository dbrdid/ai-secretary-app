# 조원 점검 가이드 (웹 시연본)

작성: MyClaw · 2026-10-08 · 브랜치 `feature/web-demo-2026-10-08`

이 문서는 조원이 로컬에서 회의록 화면을 직접 눌러 보고, 결과를 PR 댓글로 남기기 위한 절차다.
이 시연본은 **로컬 저장소(브라우저 저장)** 기반이다. 다른 기기와 동기화되지 않고, 로그인·AI·녹음은 아직 연결되지 않았다.

## 1. 실행

필요: Node.js 22.18 이상

```bash
cd ~/Projects/ai-secretary-app   # 저장소를 받은 폴더로 이동 (package.json 이 있는 곳)
git fetch origin
git checkout feature/web-demo-2026-10-08
npm install
npm run dev
```

- `npm install`은 `package.json`이 있는 폴더에서 실행한다. 홈 폴더(`~`)에서 실행하면 `ENOENT: package.json` 오류가 난다.
- 폴더 위치가 다르면 `cd` 경로만 자기 저장소 위치로 바꾼다.

브라우저에서 `http://127.0.0.1:4173` 을 연다.

## 2. 자동 테스트

```bash
npm run check        # 타입 검사 + 기능 테스트 (309개 기준)
npm run test:web     # 웹 화면 로직 테스트 (8개 기준)
```

실패가 나오면 실행 환경(Node 버전)과 출력 마지막 부분을 PR 댓글에 붙여 준다.

## 3. 수동 점검표

각 항목을 확인하고 ☐를 ☑로 바꾸거나 "문제"와 재현 순서를 적는다.

### 회의록 편집·저장
- ☐ 제목·요약·논의·결정·미확정 사항을 고치고 저장하면 새로고침 후에도 남는다.
- ☐ 할 일의 제목·담당자·기한을 고치고 저장하면 남는다.
- ☐ 내용을 고치면 검토 체크가 풀리고, 다시 체크해야 저장할 수 있다.
- ☐ 저장 실패(또는 차단) 상태에서 입력 내용이 사라지지 않는다.

### 후속 업무 요약
- ☐ 업무 수와 담당자·기한 누락 수가 실제 입력과 맞는다.
- ☐ 확인 필요 목록을 누르면 해당 입력란으로 이동한다.

### 다중 탭
- ☐ 탭 A에서 저장 → 탭 B(수정 중이 아닐 때)가 자동으로 최신 내용을 보여 준다.
- ☐ 탭 B에서 수정 중일 때는 입력이 유지되고, 변경 안내가 뜬다.
- ☐ 수정 중인 탭에서 오래된 내용을 저장하려 하면 차단된다.
- ☐ "최신본 불러오기"를 누르면 수정 내용을 버릴지 먼저 묻는다.

### 종료 후 복원
- ☐ 브라우저를 완전히 닫고 다시 열어도 마지막 저장본이 남는다.
- ☐ 저장하지 않은 편집은 사라진다(정상 동작).

### 좁은 화면
- ☐ 브라우저 창을 좁혀도(약 320px) 가로 스크롤 없이 버튼·입력란이 보인다.

## 5. 아직 하지 않는 것 (점검 제외)

- 실제 로그인, 이메일 인증, 소셜 로그인
- 녹음·음성 인식·사진 글자 인식·AI 분석
- 동시에 같은 회의록을 두 탭이 정확히 같은 순간에 저장하는 경우(충돌 방지 보류)
- 모바일 실기기, Safari·Firefox 등 Chrome 외 브라우저
